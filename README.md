Ecommerce App
==========

Overview
--------

The Ecommerce App is a SwiftUI-based snack delivery application that allows users to browse snacks, view menus, and place orders. The app integrates simple UserDefault for data saving, ensuring that users can come and go but the data added in cart will be there. This Project is just to sample application to test my Swift UI skills in picture.

Features
--------

*   **SwiftUI Interface**: A modern and smooth UI for a seamless user experience.
    
*   **UserDefault Integration**: Temprarely stores user data.
    
*   **Snacks Listings**: Displays a collection of snacks.
    
*   **Cart & Checkout**: Enables users to add items to the cart and proceed to checkout.

*   **Sidebar** : User can open sidebar to go to cart view.

*   **Filtering** : User can filter the snack on the basis of their type.
    

Technologies Used
-----------------

*   SwiftUI - For building the user interface.
